Execution Chain 07 / 09
Engineering
Four Decisions That Matter
Decision 01
user_id never an LLM argument
Extracted from Cognito JWT in FastAPI middleware. Injected directly into ADK session state. Tools read it from session_state — the LLM never sees it.
→ Prevents prompt injection from escalating to cross-user data access
Decision 02
Rules checked before synthesis
FantasyContextAgent fetches active rules during data gathering and writes them to short-term memory. Root agent reads them before proposing any picks.
→ Eliminates the validate→revise loop; submission is a safety net
Decision 03
Parallel data gathering
Three sub-agents run concurrently via ADK ParallelAgent. Each writes to session memory independently. Root reads after all three complete.
→ Total latency 15–20s sequential reduced to 5–10s
Decision 04
Tier filtering via Gateway JWT
User's Cognito JWT (custom:tier) is forwarded to AgentCore Gateway as Bearer token. Gateway uses it to filter available tools via semantic discovery.
→ Free: 8 tools. Premium: all 11 (weather, odds, Reddit)
